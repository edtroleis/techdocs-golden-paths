# Glossário

Canary
:   Deploy de uma nova versão para uma fração pequena do tráfego antes de liberar para todos.

Expand/contract
:   Padrão de migração de banco em duas fases que mantém compatibilidade entre versões.

RED
:   Rate, Errors, Duration: as três métricas mínimas de um serviço.

SLO
:   Service Level Objective: meta de confiabilidade medida por um indicador (SLI).

SCA / SAST
:   Análise de dependências (Software Composition Analysis) e análise estática de código.
