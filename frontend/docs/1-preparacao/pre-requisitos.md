# Pré-requisitos

- [ ] Time dono definido (Group no catálogo).
- [ ] Domínio/subdomínio solicitado.
- [ ] Storage de objetos e distribuição de CDN provisionados (via template de infraestrutura).
- [ ] Ambiente de desenvolvimento com Node.js LTS: de preferência um workspace do
      [OpenShift Dev Spaces](http://localhost:3000/docs/default/component/manual-dev-spaces), que já traz o Node; ou o Node instalado localmente.

```bash
nvm install --lts
corepack enable
node -v
```
