# Pré-requisitos

- [ ] Time dono definido (Group no catálogo).
- [ ] Domínio/subdomínio solicitado.
- [ ] Storage de objetos e distribuição de CDN provisionados (via template de infraestrutura).
- [ ] Node.js LTS instalado (no Windows, dentro do
      [WSL](http://localhost:3000/docs/default/component/manual-wsl)).

```bash
nvm install --lts
corepack enable
node -v
```
